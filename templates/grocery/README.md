# 🛒 Grocery — بقالة

Template used by the KAkAo builder when a user asks for: بقالة, سوبرماركت, خضار, فواكه, grocery, supermarket, market.

**Screens:** Home • Products • Search • Cart • Checkout • WhatsApp Order • Booking • Contact • Map • Reviews • Admin Panel

| File | Purpose |
|---|---|
| `template.json` | Source: colors, sections, categories and products in Arabic + English. Edit this. |
| `design.ar.json` / `design.en.json` | Ready designs (generated by `node templates/sync.js`). Drop one into `templates/_flutter-app/assets/design.json` to build a standalone APK. |

Colors: primary `#166534`, accent `#84CC16`, background `#F7FEE7`.
